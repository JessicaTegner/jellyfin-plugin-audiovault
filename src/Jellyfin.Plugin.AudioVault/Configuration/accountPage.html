Your AudioVault account

Jellyfin uses this account to download audio-described titles from AudioVault when you press play. Each account can download up to 25 titles a day. This server only counts the downloads it makes itself: titles you download from AudioVault in a browser or another app are not counted here, so if you also download elsewhere, keep an eye on your total. Your password is used once to sign in; the server then keeps an encrypted sign-in token instead of the password.

How it works

  • Add your AudioVault login once.
  • The first time a title is played, this server downloads it from AudioVault. A movie starts within a few seconds while it downloads; a season starts once the whole season has downloaded, usually within a few minutes. After that it starts straight away for everyone on this server.
  • Each download uses one of your account's daily downloads, up to the limit this server sets. Once your login is added, the status above shows how many you have used.
  • Your login is only for you. Other users and admins can't see or change it in Jellyfin's settings, and your password isn't kept unless this page says so.

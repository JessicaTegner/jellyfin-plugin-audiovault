      AudioVault accounts

      Each Jellyfin user downloads with their own AudioVault account. Users can add their own at the AudioVault account page (open it in a browser where they are signed in). Only each user can see or change their own login. Logins are checked with AudioVault when saved. Only an encrypted AudioVault sign-in token is kept, not the password (unless AudioVault provides no token).

      Connection

      Only used if Cloudflare blocks the server, for example http://flaresolverr:8191

      Playback

      The address every device and this server use to reach Jellyfin, written into the library files, for example https://jellyfin.example.com.

      Shows whether this device can reach this server at the playback address; other devices may differ.

      AudioVault bans accounts that download more than 25 titles in a day. A season counts as one download. The plugin counts only the downloads made through this Jellyfin server: downloads in a browser or another app with the same AudioVault account are not seen, so if users also download elsewhere, set this well below 25.

      Web client

      Lets every user open the AudioVault account page from the web client's menu. Users see the change after reloading the web client.

      Users

      A deleted user's stored AudioVault login is always removed from this server. With this on, the plugin also signs that login out at AudioVault, which ends "remember me" on every device using that AudioVault account, including other Jellyfin users who share it.

      Versions and languages

      Adds titles whose audio description is in another language, and other-language versions of titles that also have one in your preferred language. Your preferred language always comes first.

      Folders

      Titles removed from the cache have to be downloaded again.
      Removes the least recently played titles that nobody is playing, so new titles can still be prepared. Removed titles have to be downloaded again. When off, new plays are refused until you free space yourself.
